# 面试自我介绍（约 2 分钟）

各位面试官好！我叫梁爽，是合肥大学软件工程专业在校生，求职意向是 AI 应用开发实习生，每周可到岗 5 天，可实习 6 个月。

我主攻 Python 与 AI 应用开发，熟悉 FastAPI，能用 LangChain、LangGraph 构建智能体（Agent）应用，掌握 RAG 全链路开发，平时也习惯用 AI 工具辅助编码和调试。下面重点介绍两个项目。

第一个项目是《智能健身教练系统》。针对健身人群训练数据零散、知识获取低效的痛点，我用 LangGraph 搭建了 ReAct Agent，让 AI 教练根据用户意图自动路由到训练记录、训练查询、进展分析、知识库问答、长期记忆五个工具。项目有三个亮点：第一，混合检索——稠密向量与 BM25 稀疏向量双路融合，并针对 BM25 中文分词不准的问题引入 jieba 优化，召回率从 95.2% 提升到 97.6%；第二，引入 BGE-reranker-v2-m3 多语言重排序模型做精排，最相关的结果从平均 92.9% 稳定到 96.4% 的倒数排名；第三，给 Agent 补上了"记住用户"的能力：对话后异步用 LLM 提取候选记忆，按相关性、特异性、未来有用性、非冗余性四个维度加权评分，只有重要性 ≥ 0.6 的才写入向量库，存储噪音率控制在 15.4%。另外，写训练记录前我加了人在回路确认，Agent 会先暂停、把解析结果交用户确认，确认后再落库，而且这个暂停状态存在 Postgres 里，服务重启也不会丢。这个项目让我完整掌握了 Agent 编排、混合检索、记忆管理到效果评测的全流程。

第二个项目是 CareerPilot 多智能体求职助手。我用 LangGraph 编排了简历分析、JD 解析、岗位匹配、模拟面试等 5 个 Agent，实现简历与岗位的量化匹配。项目有两个亮点：一是集成了 GitHub MCP Server，让 Agent 能读取真实仓库的代码与提交记录来评估项目质量，我针对 MCP 返回数据多层嵌套的问题自行设计了解析器，工具调用成功率做到 100%；二是针对用户反复用同一份简历对比不同岗位的痛点，用 Redis 对分析结果做缓存，相同请求的响应时间从 15~45 秒降到 50 毫秒以内，且 Redis 不可用时能静默降级、不阻塞主流程。最后我还用 DeepEval 搭建了自动化评测管线，通过适配层解决裁判模型不支持 DeepSeek 的问题，5 组用例 3 项指标全部达标。

这两个项目从需求分析、架构设计到工程实施都是我自己独立完成的，既有算法细节的钻研，也有工程化的落地。希望能有机会加入团队，向各位前辈学习，谢谢！
